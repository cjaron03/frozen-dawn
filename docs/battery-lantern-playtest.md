Default difficulty is selected and locked before join; a world-local datapack after `mod_data` filters advancements. Late vacuum is paused at 2,592,000 apocalypse ticks. Hotbar supplies include 16 empty lanterns, another 500 J cell, a full cell, supports and a Binder. The chest has crafting supplies and spare cells. Survival mode includes lab-only resistance against vacuum damage; Creative breaking normally deletes blocks, so actual pickup must use Survival. No reset/refill function is provided.
