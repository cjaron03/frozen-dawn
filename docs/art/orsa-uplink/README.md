# ORSA Uplink original art

Authored in code for Frozen Dawn on 2026-10-17 by `make_textures.py`. No third-party textures, models or source images. The palette follows the ORSA machine set: gunmetal, copper trim, cyan listening light and amber/red transmit light. All textures are 16x16.

- Console: three front states (idle, listening carrier trace, transmitting level bars), plus side louvres, top coax port and back panel. The bottom reuses `induction_furnace_bottom`.
- Dish: a tilted reflector (`-22.5°`) on a mast, with a feed arm and horn, in four horizontal facings.
- Items: Signal Processor (relay board) and Feed Horn (pyramidal waveguide horn).

`contact-sheet.png` previews every texture. Paths and hashes are listed in `manifest.json`. Running the script again regenerates the textures, models, blockstates and manifest.
