# ORSA GPR-4 Plumb Line original art

Authored in code for Frozen Dawn on 2026-10-17 by `make_textures.py`. No third-party textures, models or source images. Five 16x16 textures in the ORSA machine palette:
- a radar display front with a ground line and echo arcs, plus a pulsing variant with amber arcs and returns;
- louvred sides;
- an antenna-grille top;
- an emitter plate with copper rings underneath.

`contact-sheet.png` previews them; `manifest.json` lists paths and hashes.
