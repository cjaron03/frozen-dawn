# Power storage concepts

Three original coordinated concept sheets generated with the built-in imagegen tool on October 14, 2026. Each shows Power Cell, four-cell Battery Bank and single-cell Cell Dock, with pixel-art icon/front designs and a voxel preview. These are enlarged design sheets for 16x16 assets, not production texture atlases or exact 16x16 PNGs. Actual native textures/model faces will be prepared after owner selection. Installed assets and the live test world are unchanged.

1. Copper Rack: graphite housings, copper hardware, cyan charge strips.
2. ORSA Field Kit: worn olive-gray, black reinforcement, brass contacts.
3. Ceramic Cartridge: off-white insulation, charcoal frames, copper caps.

## Exact prompt set

### Concept 1

```text
Use case: stylized-concept.
Asset type: original Minecraft mod concept sheet, compatible with vanilla Minecraft 16x16 textures.
Make ONE clean square pixel-art concept sheet with THREE columns: POWER CELL, BATTERY BANK, CELL DOCK. Each is a matching ORSA power-storage set for a dark frozen-world survival mod. The removable item holds energy; bank visibly holds FOUR of the same cartridge, dock holds ONE. Keep shapes instantly understandable.
Three rows: top row a crisp isolated 16x16-logical-pixel inventory icon for each of the three objects; middle row a flat front-facing 16x16-logical-pixel texture design for each; bottom row a small isometric Minecraft voxel preview of the cell, bank and dock using those same low-resolution textures. Large crisp square pixels at nearest-neighbor scale, about 16 pixels across a block face, small limited palette. Put generous neutral charcoal gutters between illustrations; simple column headings only. Flat game-ready pixel shading, no fine lines, no gradients, no bloom, no smooth photorealism, no fantasy runes, no computer display screens, no numbers, no UI overlay, no watermark. The first column cell is a removable physical battery, not a block-sized glowing crystal. The bank is a one-block rack, the dock is a simpler compact charger-sized stand with a single socket. They must be believable to build as simple Minecraft models with 16x16 textures. This is a design preview, not a packed production atlas. Direction 1: COPPER RACK. Graphite dark metal housings with warm weathered copper terminals and restrained cyan charge strips, matching a copper fork link tool. Power cell: slim rectangular copper cartridge with dark casing, two large readable copper contacts and one cyan vertical charge strip. Bank: graphite frame with four copper cartridge faces in a clear 2-by-2 arrangement, strong copper corner brackets and one tiny cyan status pixel. Dock: low graphite plinth with copper receiving collar holding one upright matching cartridge. Industrial, tactile, vanilla-like, restrained.
```
