# ORSA Power Monitor original art

Built-in imagegen generated the original front for Frozen Dawn on October 14, 2026; source PNG and exact prompt preserved here. No third-party textures, models, or source images were incorporated. Source: generated-front.png, PNG raster. Creator: built-in imagegen prompted for Frozen Dawn. Processing: export_textures.py resamples to exact16x16 and maps to a documented13-color palette, then recolors display accents for Not linked, Normal, Battery backup, Brownout and No power. Exact native texture paths/hashes are in manifest.json. No new third-party notices introduced.

The thin native block model uses the original furnace's steel bottom texture as casing, sharing existing authored material. Front state graphics indicate operating state; the little meter motif is a state icon, not a quantitative in-world battery gauge. Open the simple monitor screen for actual supply/demand, battery numbers/bar and paged device names waiting for power. No emissive shader, bloom, animation dependency or extra power draw. All front textures are opaque16x16; native model collision matches horizontal wall attachment. All four facings and five states are explicit native model variants.
