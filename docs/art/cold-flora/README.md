# Cold Flora original art

Authored in code for Frozen Dawn on 2026-10-18 by `make_cold_flora.py`. No third-party textures, models or source images. The same script writes the Rimewood and Frostcap models, blockstates, loot tables, recipes, tags, worldgen files and the hidden advancement, so it can be re-run to regenerate them. Tag files are merged, never overwritten.

- **Rimewood** follows the Blind Playtest (Oct 7) appearance table:
  - charcoal bark with deep cracks and icy-blue seams;
  - silver-grey rings around a muted blue heart;
  - desaturated grey-blue planks;
  - midnight-teal needles with frosted tips and gaps;
  - a dark sapling with two frosted branches;
  - a door with a frosted window;
  - signs and hanging signs.
- **Frostcap** is a pale foxfire fungus. It comes as a cluster or a log shelf in three ages, with item art for frozen, thawed, mush, dried and stew.
- **Rimewood Resin, the Sulfur Igniter and the Thermal Binder** have item icons.

`contact-sheet.png` previews the textures; `manifest.json` lists paths and hashes.
