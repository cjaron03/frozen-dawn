# Conduit Binder concepts

Three original concepts generated with the built-in imagegen tool on October 12, 2026. Native deliverables are exactly 16 by 16 pixels with binary transparency; previews enlarge those same pixels using nearest-neighbor sampling. Generated originals are preserved. At generation, these concepts were awaiting owner selection; the installation decision is recorded below.

Prompt set: vanilla Minecraft inventory pixel art, graphite handle, copper hardware and cyan energy, transparent background, simple diagonal silhouette, a 16 by 16 logical grid, no text or background.

1. Copper Fork: two copper prongs around a cyan energy center.
2. Coil Wand: a copper coil and cyan crystal cap.
3. Relay Key: a square copper ring with cyan center and short keyed shaft.

Original generation outputs were larger than the requested native grid. Exported each to exact 16 by 16 with nearest-neighbor sampling and binary alpha.

Owner selected Copper Fork; its exact 16x16 PNG is now installed as the Binder item texture. The other two concepts remain alternatives.
