This slice observes loaded known room memberships and consumers. It never changes oxygen availability, starves a burner, adds air, or changes pressure/heat. Pressure and breathable oxygen separation, saved furnace starvation/restart, tank storage and charging allocation, and Core energy-budget migration remain subsequent slices.

One sustained player breathing rate is one unit. Core and existing Blast Pit anchors each provisionally supply 8. Sources must lie inside or directly touch a room; adjacency is within the existing minimum O2 ranges. Upgrades continue changing existing range, not diagnostic capacity. Shared source/room edges form connected pools, with each source counted once. Independent rooms receive no capacity across unrelated sealed walls. A burner touching multiple rooms is counted once in the lowest canonical room ID; it cannot join unrelated supply pools.

The existing VacuumFlames loaded-chunk index is reused; no second chunk scanner is added. Initial bounded scans expose pending chunk identities. For a source touching a known room, at most two unknown loaded neighboring intakes are inspected per accounting update. This discovers an unvisited room directly served by the same source before reporting a safe pool. Unrelated remote terrain is not discovered. Cached topology indexes cells/intakes/chunks only on room changes; burner membership updates on its index revision and topology/source changes. Every 20 ticks, loaded occupants are sampled using their feet cell: Survival/Adventure = 1, Creative/spectator = 0, ordinary animals by the source weights, undead horses = 0. Other named vanilla animals have approximate masses; unknown Animal types default to 1. Babies use half adult demand as a provisional balance choice. Returned/Architects are not Animal consumers. Unknown geometry, unloaded bounds, pending consumer bootstrap or a truncated >16384-entity sample produces WAITING; a shared pool cannot show supported while a known member is incomplete.

Ordinary torch/lantern = .25, each lit candle = .25, fire/campfire/MiteAway flame = 1, lit furnace/smoker/blast furnace = 3. Soul flames and sealed Thermal Heaters remain zero. Constants are first-pass balance, not physical oxygen concentrations. Source/demand collections reconstruct after reload; no new SavedData stores or duplicates capacity. /fd world oxygen reads cached records without discovering/renewing/refilling rooms.
