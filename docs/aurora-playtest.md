Natural events use a server-derived visual seed and absolute day time. Eligible-night chances are 18%, 40%, 25%, and 12% for phases 0–3, before weather and night visibility. Activity fades at both ends and declines to zero approaching phase 4. Daytime and phases 4+ are hidden. Save/reload reconstructs the same event; natural activity does not use a client lottery. Curtains face world north with seeded variation.

The renderer runs after the sky, before terrain, clouds, and weather. The cloud mask samples the resource pack's actual `clouds.png`, using vanilla's 12-block texture scale, renderer tick drift, and cloud-plane offsets. It covers the cloud slab while keeping upward views from above clouds clear. Weather attenuation remains when visual clouds are disabled. Shader-pack cloud replacements are not a verified integration.
