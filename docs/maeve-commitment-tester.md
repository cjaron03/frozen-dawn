# Encounter playtest

Please do this before reading implementation notes or discussing the encounter with someone who has already played it.

In the supplied disposable world, run `/function maeve_playtest:setup_blind`. The first part practices using potions: finish the potion in slot 1 when prompted. There are four rounds, with a short automatic wait between them.

When practice is complete, click the start prompt or run `/function maeve_playtest:encounter`. Use the space and supplies as you see fit. Keep the Architect alive until the encounter pauses after 30 seconds.

After the pause, describe what happened and anything that stood out, in your own words. Give that description before opening explanations or discussing it with the developer. There is no particular answer you need to give.

After your description has been recorded, run `/fd maeve dump` so the developer can examine the encounter. If something prevents you from playing, report exactly what happened.
