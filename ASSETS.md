Unless a file is explicitly documented as third-party, every Frozen Dawn asset in this repository is an original project asset created for Frozen Dawn by Jaron Cabral.

## Original Branding and Interface Art

- ORSA logo, O-mark, masthead, motto treatment, boot logo, and Patchouli masthead art
- ORSA First Awakening intro art, including the masthead base and animated yellow stripe overlays
- Terminal, thermal visor, HUD, diagnostic, and ORSA boot interface presentation assets
- All GUI textures in `src/main/resources/assets/frozendawn/textures/gui/`
- All final replacement UI textures shipped under `src/main/resources/assets/minecraft/`, including HUD, container, widget, advancement, and splash presentation assets

The `assets/minecraft` files are original Frozen Dawn replacement UI textures authored for in-game compatibility. They are not copied, traced, recolored, or mechanically derived from Mojang/Microsoft texture assets.

## Original Game Textures

- All block textures in `src/main/resources/assets/frozendawn/textures/block/`
- All item textures in `src/main/resources/assets/frozendawn/textures/item/`
- All entity and model textures in `src/main/resources/assets/frozendawn/textures/entity/` and `src/main/resources/assets/frozendawn/textures/models/`
- All slot and miscellaneous textures in `src/main/resources/assets/frozendawn/textures/slot/` and `src/main/resources/assets/frozendawn/textures/misc/`
- Frozen terrain, sulfur, volcanic, ORSA machine, transponder, radio, supply crate, forge, fuel silo, rocket, armor, survival gear, document, and late-game material textures

## Original Map, Ending, and Release Art

- Mars ending cubemap art in `src/main/resources/assets/frozendawn/textures/gui/ending/`
- Monitoring-station map art in `src/main/resources/data/frozendawn/map_art/`
- README and release screenshots in `docs/images/`
