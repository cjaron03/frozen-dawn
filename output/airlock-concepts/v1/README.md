# Airlock concept art — v1

Generated with the built-in image_gen tool on October 9, 2026. These enlarged pixel-art concepts are for owner review. They are not native-resolution texture exports and are not installed in the game. Original generated files are preserved. Exact prompts, source paths and SHA-256 hashes are in prompts-and-provenance.json.

- Door: steel frame, small cyan inspection window, rubber seal and mechanical latch. Later native assets: two 16x16 block-face halves and an inventory icon.
- Controller: red evacuated/fault, amber cycling, green breathable fronts and a matching casing. Later native assets: three 16x16 front states and casing faces. Optional side panels reuse the same controller design.
- Emergency vent: red manual wheel, grille and warning markers. Later native assets: 16x16 front and matching casing, with a model appropriate for manual operation.

Gameplay, models, recipes, reserve accounting and live acceptance of custom airlock parts remain pending. See docs/airlock-design.md for the agreed mechanic contract.
