# Emergency EVA presentation assets

The emergency visor tape is an AI-assisted original game texture generated with
OpenAI image generation on 2026-10-04 from this project's prompt. No external
photograph, Minecraft texture or third-party texture was used as reference.
An initial generated woven-tape sprite was edited by the same image tool into
chunky Minecraft-style pixel art at the owner's explicit request. It is not
claimed as wholly hand-drawn owner art. The final output is retained unchanged
in `textures/gui/emergency_visor_tape.png`; runtime UVs frame its opaque strip.
Nearest-neighbor sampling is explicitly enabled in the texture metadata.

The prompt required one transparent, torn silver-grey outer-visor tape strip,
coarse square pixel clusters, muted grey/charcoal with dirty adhesive edge
pixels, cloth folds and a lifted end, with no text or borrowed branding.

Final PNG SHA-256: `afe7d9761d2f2405f13b3fbc5df75fa4f654a119719a7860e813107714e2ec18`.

`EmergencyEvaSuitLayer` bottle, regulator, pull-tab, harness, collar, repair
patches and pack label geometry are original project code. The label uses the
existing ORSA blue stripe. The 32x32 neutral weave material is generated by
`generate_material.py` using original deterministic pixel placement. It is
not copied from vanilla armor. Remote rendering uses the synced equipped
item identity, so it does not depend on owner-only emergency state sync.

The first-person tape repairs the outer visor only. Moisture is cosmetic;
no repair, seal or health mechanic is implied. It builds with actual reserve
service age and synced exertion and recovers more slowly than oxygen draw.

The full-screen condensation film (`emergency_visor_mist.png`) is original
project art generated offline by `generate_mist.py`, using seeded multiscale
noise, continuous seal-edge falloff and sparse softened wet trails. No borrowed
images or AI-generated inputs are used. The 512x256 RGBA texture has positive
alpha everywhere, a lighter center and denser uneven peripheral mist. Linear
sampling and clamping avoid sharp cells and repeating seams. One full-screen
quad replaces the per-frame pixel/droplet loops and their rectangular HUD
exclusion. Vanilla and ORSA instruments render above the complete visor layer;
readability comes from layer order. No framebuffer blur is used. The tape
bitmap retains its original nearest-neighbor sampling and hash.

Full-screen mist PNG SHA-256: `411b3b694fa2ff6de5e0f5163e06477f898fcfc31240a66e1b46de4cef805849`.
