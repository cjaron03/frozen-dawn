# Master Architect and Thae Iven audio provenance

**Review date:** 2026-08-27
**Rights status:** cleared by project-owner authorship declaration

The project owner, Jaron Cabral, declares that the Frozen Dawn Master Architect
and Thae Iven audio listed below was authored for Frozen Dawn. No third-party
recordings, samples, game assets, generated voice performances, or external
music are declared as inputs to these files. On that declaration, the underlying
copyright remains with the project owner and is not covered by the repository's
`LGPL-3.0-or-later` code license.

This is an authorship record, not a forensic proof of the creative process. If a
file contains a third-party recording or generated performance, this ledger must
be amended with the source URL, creator, license/version, retrieval date,
processing steps, and any required attribution before release.

authorship declaration.
